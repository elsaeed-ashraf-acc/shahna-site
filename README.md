# شحنة | الموقع التعريفي للخدمات اللوجستية والتوصيل في دولة الإمارات

موقع تعريفي احترافي ومتجاوب بالكامل لشركة **شحنة (Shuhna Logistics)** للتوصيل والشحن السريع ونقل الركاب داخل دولة الإمارات العربية المتحدة، مبني باستخدام **React 19** و **Vite** و **Tailwind CSS**. الهاتف: `+971509091885`.

---

## 🚀 المميزات الرئيسية

- **هوية بصرية جديدة ومستقلة**: تصميم عصري أنيق يعتمد أحدث معايير تجربة المستخدم وتوافق تام مع اللغة العربية (RTL).
- **أقسام متكاملة**:
  1. **الرئيسية (Hero)**: عنوان تسويقي قوي، صورة أسطول سينمائية، أزرار واتساب ومكالمات مباشرة، وشريط إحصائيات التغطية.
  2. **من نحن (About Us)**: نبذة الشركة، معايير الأمان، وجدول تغطية كافة إمارات الدولة (دبي، أبوظبي، الشارقة، عجمان، رأس الخيمة، الفجيرة، أم القيوين، العين).
  3. **الخدمات اللوجستية (Services)**:
     - مندوب توصيل فوري (Same-Day Express Courier)
     - شحن بين كافة الإمارات (Inter-Emirate Shipping)
     - نقل وتوصيل ركاب وأفراد بين المدن (Intercity Passenger Transport)
     - الخدمات اللوجستية وتوزيع طرود المتاجر الإلكترونية (E-Commerce Delivery & COD)
  4. **حاسبة استفسار التوصيل**: تتيح للعميل اختيار إمارة الاستلام والتسليم ونوع الخدمة وتوليد رسالة واتساب جاهزة ومجهزة تلقائياً.
  5. **الأسئلة الشائعة (FAQ)**: أكورديون تفاعلي لأهم أسئلة العملاء.
  6. **اتصل بنا (Contact)**: بطاقات التواصل المباشر، زر نسخ رقم الهاتف، ونموذج إرسال استفسار.
  7. **أزرار عائمة (Floating CTA)**: زر واتساب مباشر وزر اتصال وزر الرجوع للأعلى.

## 🛠️ دليل التخصيص السريع (تعديل الهوية وأرقام التواصل)

جميع نصوص الشركة وأرقام التواصل وشعارها مجمعة داخل ملف مركزي واحد:
```bash
src/data/companyConfig.ts
```

### خطوات التعديل:
1. **اسم الشركة وشعارها**:
   عدّل الحقول `name` و `englishName` و `slogan`.
2. **رقم الواتساب**:
   عدّل حقل `contact.whatsappRaw` بالرقم الدولي الجديد دون علامة + (مثال: `971501234567`).
3. **رقم الاتصال المباشر**:
   عدّل حقل `contact.phoneDisplay` بالصيغة المعروضة (مثال: `+971 50 123 4567`) و `contact.phoneTel` بالصيغة الفعلية للاتصال (`+971501234567`).
4. **البريد وساعات العمل**:
   عدّل حقول `contact.email` و `contact.workingHours`.

## 🌐 النشر على Vercel وربط الدومين الجديد

1. **الرفع على GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for UAE logistics landing page"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```

2. **النشر على Vercel**:
   - توجّه إلى [vercel.com](https://vercel.com) وسجّل الدخول بحساب GitHub.
   - اضغط **Add New Project** واختر المستودع.
   - سيقوم Vercel تلقائياً باكتشاف مشروع Vite (`Build Command: npm run build`, `Output Directory: dist`).
   - اضغط **Deploy**.

3. **ربط الدومين المخصص (Custom Domain)**:
   - داخل لوحة تحكم مشروعك في Vercel، توجّه إلى **Settings > Domains**.
   - أضف الدومين الخاص بك (مثال: `yourdelivery.ae` أو `www.yourdelivery.ae`).
   - قم بإضافة سجلات DNS (A Record / CNAME) المعطاة من Vercel داخل لوحة مزود الدومين الخاص بك.
   - سيتم تفعيل شهادة الأمان SSL مجاناً وتلقائياً خلال دقائق.
